## Наблюдение для будущих проверок

`pkill -f '…/backend/target/debug/backend'` (полный путь) не матчит
запущенный бинарник — его cmdline относительный (`target/debug/backend`),
при этом матчит сам shell с этой строкой и убивает его. Результат:
осиротевший процесс держит 8081, следующая проверка даёт ложный
результат. Правильно: `pkill -f '[t]arget/debug/backend'` и перед
каждым live-тестом проверять, что порт свободен.
